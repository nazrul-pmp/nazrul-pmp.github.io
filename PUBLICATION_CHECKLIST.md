# Publication Checklist

Use this checklist before making the site public.

- [ ] Confirm the current professional title and employer wording.
- [ ] Confirm that every quantified achievement is still accurate.
- [ ] Confirm permission/anonymization for each case study.
- [ ] Decide whether a public email address should be displayed.
- [ ] Decide whether to add a downloadable CV.
- [ ] Add a professional photo only if you want it publicly visible.
- [ ] Check LinkedIn URL.
- [ ] Review spelling, dates and organization names.
- [ ] Test the site on mobile and desktop.
- [ ] Remove any content that conflicts with employer confidentiality requirements.

The current package was intentionally designed to avoid publishing salary, private contacts, home address,
supervisor details and source evidence documents.
