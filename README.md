# Mohammed Nazrul Islam — Professional Portfolio Website

This is a static, responsive portfolio site designed for free hosting on GitHub Pages.

## Files
- `index.html` — website content
- `styles.css` — visual design and responsive layout
- `script.js` — mobile navigation and subtle scroll reveal
- `assets/favicon.svg` — site icon
- `robots.txt` — search-engine crawl permission
- `site.webmanifest` — basic web-app metadata

## Publish free with GitHub Pages

1. Create a new **public** GitHub repository, for example `portfolio`.
2. Upload all files in this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the live website URL after deployment.

For a personal GitHub Pages address such as `username.github.io`, name the repository exactly `username.github.io`.

## Before publication
The current version intentionally excludes:
- phone numbers
- personal/home addresses
- compensation
- supervisor contact details
- confidential donor/project records
- unapproved source documents
- private email address

The case studies are written as portfolio-safe summaries and minimize organization/donor-sensitive detail.
